## 🚀 **Quick Start Instructions:**

1. **Install Python 3.8+** and pip
2. **Run the launcher:** `python launch.py --setup`
3. **Add your API keys** to `.streamlit/secrets.toml`
4. **Launch the app:** `python launch.py`
5. **Try the demo:** `python launch.py --mode demo`
